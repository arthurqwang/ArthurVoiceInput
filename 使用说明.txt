阿色语音快捷输入法（讯飞版）
================================
按住鼠标说话，松开即识别并输出到光标处。Windows 屏幕常驻输入法。
快捷热键：按住 Ctrl+Alt+Space 说话，松手同样识别输出。

项目主页（GitHub）：https://github.com/arthurqwang/ArthurVoiceInput

------------------------------------------------
一、直接使用（无需安装 Python 环境）
------------------------------------------------
  双击 ArthurVoiceInput.exe 即可运行。
  * 仅支持 64 位 Windows（Win8.1 及以上）
  * 需要麦克风 + 联网（识别走讯飞云端）

------------------------------------------------
二、首次使用：申请讯飞密钥（免费）
------------------------------------------------
  1. 打开 https://www.xfyun.cn 注册账号（免费额度每日 500 次）
  2. 控制台 → 创建应用 → 语音听写 iat
  3. 获取 APPID / APIKey / APISecret 三项密钥
  4. 启动程序 → 右键屏幕上的输入法图标 → 「配置」
     → 填入三项密钥 → 保存

------------------------------------------------
三、使用方法
------------------------------------------------
  * 在欲输入位置长按鼠标左键（约 0.3 秒），
    呼出输入图标（淡红色麦克风）
  * 按住图标说话 → 松开自动识别并输出到光标
  * 全局热键：按住 Ctrl+Alt+Space 也可录音
  * 右键图标菜单：配置 / 帮助 / 隐藏 / 重启 / 退出

------------------------------------------------
四、开机自动启动
------------------------------------------------
  右键图标 → 配置 → 勾选「开机自动启动」即可。
  （日志/配置/语音速记均生成在 exe 所在目录）

------------------------------------------------
五、从源码运行（开发者）
------------------------------------------------
  1. 安装 Python 3.13（需带 tkinter）
  2. pip install -r src/requirements.txt
  3. python src/voice_input.py
  4. 重新打包 exe：python src/build_exe.py（需先 pip install pyinstaller）

------------------------------------------------
六、常见问题
------------------------------------------------
  * 杀毒软件误报：exe 未签名，添加信任即可
  * 首次启动较慢（约 1~3 秒）：音频/COM 组件初始化，属正常
  * 识别为空/乱码：确认麦克风正常、网络畅通、说话清晰
  * 讯飞免费额度 500 次/天，每次最长一分钟
